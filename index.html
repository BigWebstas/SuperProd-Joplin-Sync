Joplin Notes Sync

Update available: — download it from GitHub, then reinstall it under Settings → Plugins.

Pushes each Super Productivity project's notes into a matching notebook in your local Joplin app. Project notes are one-way (Super Productivity → Joplin) — the plugin API has no way to write that content back. Optionally, each task's own notes can also sync — two-way by default (edits in either app reach the other), or one-way like project notes if you'd rather Super Productivity always win. Desktop only.

1. Joplin API token not set

  1. In Joplin, open Options → Web Clipper and enable the service.
  2. Copy the Authorization token shown there.
  3. Paste it below and save. It is stored locally on this device only.

2. Current settings

Read-only summary. Change these in Settings → Plugins → Joplin Notes Sync.
