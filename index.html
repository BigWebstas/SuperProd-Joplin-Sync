Joplin Notes Sync

Pushes each Super Productivity project's notes into a matching notebook in your local Joplin app. Project notes are one-way (Super Productivity → Joplin) — the plugin API has no way to write that content back. Optionally, each task's own notes can also sync — those go both ways, so edits in either app reach the other. Desktop only.

1. Joplin API token not set

  1. In Joplin, open Options → Web Clipper and enable the service.
  2. Copy the Authorization token shown there.
  3. Paste it below and save. It is stored locally on this device only.

2. Connection settings

Joplin URL, parent notebook name, auto-sync interval, and whether task notes are synced are configured in Settings → Plugins → Joplin Notes Sync.
